Recommended refinements following the v3 raster publication review

Publication reviewed:
/cw3e/mead/projects/cwp206/agentization/hydro_ops/web/publications/pilot-v3-20261112/

Overall assessment: v3 addresses nearly all concrete problems identified in
the previous review and is ready for a controlled browser integration pilot.
Keep the existing publication structure. These refinements will improve the
long-term convention and the next, more complete collection of days.

1. Make unit and percentile-scale conventions machine-readable and consistent.

Temperature uses Cel in variable definitions but degC in legends. These mean
the same thing, but require alias handling. Choose a canonical unit vocabulary
and document aliases.

Percentiles use unit 1, a textual encodedScale of "0-100", and legend unit %.
Explicitly declare that numerical rank values and legend thresholds use the
same 0-100 scale, so a consumer cannot accidentally multiply them by 100.
Prefer structured numeric scale/range metadata over a prose-only convention.
Percentile ranks must remain dimensionless during display-unit conversion.

2. Strengthen climatology provenance.

The daily acceptance-file checksums are useful, but monthly table job IDs alone
are not durable identifiers of the actual tables. Add table checksums or
immutable dataset/version references. Production paths can remain
provenance-only references rather than downloadable assets.

3. Reduce duplicated scientific definitions.

Family-level statistics repeats material now maintained in variables.json.
For example, the family says low SWE produces "missing ranks", while the
variable definition more precisely describes valid SWE with intentionally
suppressed ranks.

Reference the shared definition, or clearly label family text as a
nonauthoritative summary. Keep valid-but-suppressed estimates distinct from
missing source estimates in terminology and quality metadata.

4. Document completeness requirements for daily/monthly aggregates.

The aggregation itself is now clear. Document what happens when some hourly
or daily inputs are missing: required sample count, weighting, and whether
incomplete intervals are rejected or retained. This differs from the already
documented minimum sample counts for the climatology.

5. Add targeted validation cases.

The current samples exercise hidden precipitation, missing estimates, and
suppressed SWE. They do not exercise positive invalidEstimate or
statisticUnavailable counts, and include no February 29 date.

Include representative cases when available in the expanded collection.
Small, explicitly labeled fixtures can exercise otherwise absent conditions;
keep synthetic fixtures distinguishable from published scientific data.

NEXT VALIDATION STEP

Proceed to browser integration alongside these refinements rather than
undertaking another broad publication redesign. Check geographic alignment,
discrete-color rendering, sparse date selection, monthly interval labels,
retro/NRT preference, and preservation of valid fully transparent images.

The v3 review checked all 76 local PNGs for checksum, dimensions, decoded color
membership, transparency, and visible-pixel counts. Quality-count partitions,
timeline references, and coverage counts were also checked. It did not
independently recompute scientific values from source archives, validate a v3
web deployment, or test browser rendering.
